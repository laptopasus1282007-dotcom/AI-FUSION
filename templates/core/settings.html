About CodeSathi AI
Empowering Beginners to Master Programming

CodeSathi AI is built specifically for students and self-learners. Rather than just handing out answers, CodeSathi breaks concepts into intuitive mental models, explains line-by-line mechanics, verifies debugging against real evidence, and reinforces retention through guided problem solving.

Evidence-Based
Every debugging output maps directly to code lines, stack traces, and verified documentation.
Multi-Lingual
Native support for explanations in English, Hindi, and Marathi to make programming inclusive.
Fix It Yourself
Progressive hints and guided questions prevent dependency on copy-pasting solutions.
RAG Grounding
Retrieval-Augmented Generation indexes course textbooks to prevent hallucinations.
Environment Configuration

To set your API keys or change the LLM provider, update the .env file in the project root: 

LLM_PROVIDER=gemini       # or openai
GEMINI_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here
YOUTUBE_API_KEY=your_key_here
